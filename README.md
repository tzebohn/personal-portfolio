# Personal Portfolio

A modern, responsive portfolio website built to showcase my projects, technical skills, and experience as a full-stack developer. This portfolio serves as a central hub where recruiters, hiring managers, and fellow developers can explore my work, learn about my development process, and get in touch with me.

---

## 🎯 Objective

Build a production-quality portfolio that demonstrates both technical ability and attention to detail while following modern web development best practices.

This project was designed to:

* Demonstrate frontend expertise with **React**, **Tailwind CSS**, and modern UI/UX principles.
* Highlight real-world projects with detailed descriptions and live demos.
* Emphasize responsive design and accessibility across all devices.
* Practice clean architecture, reusable components, and scalable project organization.
* Create a polished experience that reflects the quality expected of production applications.

---

## ✨ Features

* Responsive mobile-first design
* Interactive project showcase
* Animated hero section
* Skills overview with desktop and mobile layouts
* Project filtering and categorized technology stacks
* Frequently Asked Questions section
* Social links and contact information
* Smooth animations and micro-interactions
* Accessibility-conscious UI components
* Modern dark theme inspired by futuristic interfaces

## 📁 Project Structure

The application follows a component-based architecture to encourage scalability and maintainability.

```text
src/
├── assets/
├── components/
├── data/
├── hooks/
├── layouts/
├── pages/
├── styles/
└── utils/
```
